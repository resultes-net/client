# client

The ResulTES web UI: a SvelteKit app that talks to the external server (repo `server`).

```sh
npm install
npm run dev   # http://localhost:5173
```

For how to work on this repo, see `AGENTS.md`, and for the overall architecture the org-wide guide:
https://github.com/resultes-net/issues/blob/main/AGENTS.md.
